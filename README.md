# Parafraseador y Humanizador IA (100% Offline Portable)

Aplicación de escritorio para Windows que permite parafrasear y humanizar cualquier texto o documento (`.txt` y `.docx`) utilizando Inteligencia Artificial ejecutada 100% en local, sin necesidad de conexión a internet ni claves de API.

## Características
* **100% Offline y Privado:** Funciona sin internet procesando los textos directamente en tu PC.
* **4 Grados de Reescritura:** Básico, Estándar, Pro y Humanizado (Anti-IA).
* **Soporte de Documentos:** Carga y exportación directa de archivos `.txt` y Word (`.docx`).
* **Portable:** No requiere instalar Python ni configuraciones adicionales.

## Cómo descargar y usar
1. Ve a la sección **[Releases](../../releases)** (a la derecha de esta página).
2. Descarga el archivo `.zip` de la última versión.
3. Descomprímelo en una carpeta en tu PC o memoria USB.
4. Abre **`Parafraseador_Offline.exe`**, espera unos segundos a que el estado indique `✅ IA Lista (Offline)` y comienza a usarlo.
